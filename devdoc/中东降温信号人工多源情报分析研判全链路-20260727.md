# 人工多源情报分析研判方法——以 2026 年 7 月“美伊降温”信息为例

**案例截点：** 2026 年 7 月 27 日 16:00 CST

**分析范围：** 美国、伊朗及霍尔木兹海峡、红海等关联区域

**适用对象：** 情报分析人员、数据人员、产品人员和后续技术实现团队

本文说明分析人员如何把一条突发资讯整理成有依据、有保留意见、能持续更新的情报产品。案例从“美伊相互暂停军事行动、外交沟通仍在继续”这一最新线索出发，使用目前已经找到的新闻、官方发布入口、航空、海事、网络和市场数据说明具体做法。文中的工作均可由分析人员使用浏览器、表格、地图和普通数据工具完成，不以现有业务系统为前提。

## 1. 与 PRD 两类场景的关系

### 1.1 本案例以场景一为主

PRD 场景一从 OSINT 热点或 AIS、ADS-B、RF 异常中发现线索，经分析师确认后调取卫星影像或其他观测资料，完成多源核验并形成报告。

本案例的起点是新闻和市场异动信息。分析人员需要核对美伊双方表态，再查看军事行动、通航、民航、网络和市场是否发生相应变化。这与场景一的业务逻辑一致。

| PRD 层级 | 本案例中的人工工作 | 主要产物 |
| --- | --- | --- |
| L1 线索发现 | 从今晨资讯、媒体集中报道和市场异动描述中发现“美伊可能降温” | 线索卡、初始主张、关注区域和时间窗 |
| L2 事实确认 | 核对双方及斡旋方原文，检查军事活动、通航、航空、遥感、网络和行情数据 | 事实清单、时间线、核验矩阵、缺口清单 |
| L3 综合研判 | 比较几种可能解释，判断降温范围、稳定性和影响 | 情报简报、详细解读、预警和后续建议 |

PRD 把卫星影像作为 L2 的主要确认手段。人工研判不应机械等待影像。已有官方原文、连续遥测或权威通告足以回答部分问题时，可以先形成阶段结论，并标明卫星证据缺失。涉及设施损伤、装备数量或地面变化时，仍需影像确认。

### 1.2 场景二是本次研判的后续任务

PRD 场景二要求对固定区域持续获取多时相影像，以 T0、T1、T2 等影像识别设施、装备或活动痕迹变化。本案例目前没有形成这样的影像序列，暂不能作为场景二案例。

本次研判可以产生场景二任务。若霍尔木兹海峡通航、重点港口或能源设施被列为持续关注对象，分析人员需要确定 AOI、建立基准影像、规定复看频率，并对后续影像做变化检测。这部分属于场景二。

结论如下：

- 当前案例覆盖了场景一从线索发现到核验、报告和预警的工作过程。受一手原文和连续观测数据缺口影响，目前产出属于阶段研判。
- 当前案例提供了场景一转入场景二的任务入口。
- 只有取得连续影像并识别出跨期变化后，才能称为完成了场景二。

## 2. 研判任务的目标

### 2.1 决策问题

“美伊降温”包含事实、原因、影响和趋势四类问题。分析人员应在任务开始时确定需要回答哪些问题。

| 类型 | 本案例需要回答的问题 |
| --- | --- |
| 事实 | 美国是否暂停对伊朗打击；伊朗是否同步暂停；暂停从何时开始；适用范围是什么 |
| 原因 | 暂停是否用于给谈判留出空间；军备库存、国内政治或盟友压力是否产生影响 |
| 影响 | 霍尔木兹和红海通航是否改善；民航是否恢复；网络和基础设施是否仍有异常；市场是否持续重新定价 |
| 趋势 | 暂停能否延续 24 至 72 小时；哪些外围事件可能打断暂停；是否存在形成正式安排的条件 |
| 行动 | 分析人员下一步查什么；决策者是否需要调整航运、能源、人员和业务风险措施 |

### 2.2 本轮交付

一次完整研判应形成以下材料：

1. 初始线索和任务范围。
2. 经过去重的来源清单。
3. 标准化事件时间线。
4. 主张核验表和矛盾记录。
5. 航空、海事、网络、遥感和市场分析记录。
6. 当前判断及置信度。
7. 一页情报简报。
8. 详细解读。
9. 预警状态、监测指标和下一步建议。

### 2.3 分析边界

本案例使用公开信息研判地区安全、航运、能源和企业运营风险。公开飞行和航行数据只用于区域活动统计、通航安全和趋势分析。不推断精确军事部署，不提供打击目标、武器运用或进攻性行动建议。

## 3. 初始线索与待核实主张

### 3.1 初始线索

7 月 27 日今晨资讯称：美股期货、贵金属和加密资产上涨，油价下跌；伊朗消息人士表示，只要美国停止军事打击，伊朗也将停止军事行动；美国常驻联合国代表迈克尔·华尔兹称，美国暂停打击以给外交谈判留出空间；伊朗外交部发言人巴加埃称，双方仍在交换信息，斡旋方继续工作。

这段信息混合了四种材料：市场行情、匿名消息人士说法、美方官员表态和伊方官员表态。每项材料的核验方法不同，必须分开处理。

### 3.2 主张拆分

| 编号 | 待核实主张 | 成立所需材料 |
| --- | --- | --- |
| C1 | 美国已暂停对伊朗军事打击 | 美方公开原文或可回溯官员原话；同一时段无新打击记录 |
| C2 | 伊朗在美方维持暂停期间也暂停行动 | 伊方公开原文或可回溯原话；同一时段无新行动记录 |
| C3 | 美伊沟通和第三方斡旋仍在继续 | 美伊双方或斡旋方在同一时段的公开材料 |
| C4 | 暂停主要用于争取外交空间 | 政策表态、会谈安排及其他原因的排除情况 |
| C5 | 霍尔木兹海峡和周边通航风险正在下降 | UKMTO/JMIC、AIS、港口状态和船舶运行数据 |
| C6 | 区域航空活动正在恢复 | 固定区域内 ADS-B 航班数量、航路和高度变化 |
| C7 | 市场已持续交易“局势降温” | 油价、黄金、股指期货、VIX、美元和加密资产的盘中序列 |
| C8 | 中东整体进入持续降温 | 美伊直接行动、红海、黎巴嫩、海峡和代理人活动共同改善 |

### 3.3 待比较的解释

分析过程中保留四种解释，避免只收集支持“局势好转”的材料。

| 假设 | 具体含义 | 预期会看到的信号 |
| --- | --- | --- |
| H1 外交降温 | 双方准备把暂时停火转为较稳定安排 | 正式声明、明确会谈安排、军事活动和通航风险持续下降 |
| H2 条件性互停 | 双方暂时停止直接行动，同时保留恢复行动的条件 | 表态带有前提，沟通继续，外围摩擦未消失 |
| H3 战术性停顿 | 暂停用于补给、调整部署或观察对方反应 | 正式谈判进展有限，军事准备和高风险通告维持 |
| H4 局部降温、地区外溢 | 美伊直接行动减少，红海或其他战线仍在升温 | 美伊互停与胡塞、红海、黎巴嫩等风险并存 |

## 4. 需要准备的数据

### 4.1 数据清单

| 数据类别 | 重点来源 | 核心字段 | 解决的问题 | 当前情况 |
| --- | --- | --- | --- | --- |
| 美国官方发布 | White House、USUN、CENTCOM | 发布时间、说话人、场合、原文、修订时间、URL | 核实 C1、C3、C4 | White House RSS 可用；USUN 尚未找到对应逐字稿；CENTCOM 网页抓取受限 |
| 伊朗官方发布 | Iran MFA、IRNA | 发布时间、发言人、原文语言、译文、URL | 核实 C2、C3 | IRNA RSS 可用；Iran MFA 当前访问不稳定 |
| 斡旋方发布 | Oman MFA、Oman News Agency、Qatar MFA、Pakistan MFA | 会谈时间、参与方、议题、下一步安排 | 核实 C3 和谈判连续性 | Oman MFA RSS 可用；其他来源需网页核查 |
| 新闻报道 | Reuters、AP、NPR、France 24、Al Jazeera、TASS 等 | 标题、正文、作者、稿源、引语、发布时间、地点、URL | 发现线索，补充政策和地区背景 | 已整理 22 条相关报道，存在大量转载 |
| 冲突与安全事件 | 当事方公告、权威事件通告、可信新闻 | 事件时间、地点、事件类型、是否持续、受影响对象 | 检查实际行动是否停止 | 当前主要依赖媒体报道，独立事件序列仍需补齐 |
| 海事通航 | UKMTO/JMIC、AISStream、港口和航运通告 | 船舶数、速度、航向、等待、绕行、事件、通告时间 | 核实 C5 | AISStream 需 key；UKMTO 服务器访问受限 |
| 航空活动 | ADSB.lol 等公开 ADS-B | 航班标识、经纬度、高度、速度、航向、`seen`、快照时间 | 核实 C6 | 当前单次快照可用，尚缺连续基线 |
| 遥感与火点 | 光学/SAR 影像、NASA FIRMS | 影像时间、分辨率、云量、变化区域、热异常、置信标记 | 核实设施变化、活动痕迹和打击结果 | FIRMS 需免费 key；尚无本案例有效影像序列 |
| 网络可用性 | IODA | 国家、数据源、时间步长、观测值、缺测 | 识别大范围通信异常及其持续时间 | 已取得伊朗 GTR、Merit、Mozilla 时序样本 |
| 市场行情 | 合规盘中行情源、FRED 日频基线 | 时间、价格、涨跌幅、成交量、交易时段、合约 | 核实 C7 并区分短时冲击与持续定价 | FRED 可作日频基线；盘中主源未落实 |
| 历史基线 | 过去 7/30/90 天同口径数据 | 常态均值、波动范围、季节性、既往事件窗口 | 判断当前变化是否异常 | 需要按数据类别补齐 |

### 4.2 每条材料都要记录的字段

新闻和官方材料至少记录：

- 来源机构和作者；
- 原始标题和中文译题；
- 原始发布时间、时区和统一后的 UTC 时间；
- 原文 URL、发现时间和快照位置；
- 说话人、原话、转述层级；
- 涉及的主张；
- 是支持、反驳、补充背景还是重复报道；
- 与其他来源的引用或转载关系；
- 无法确认的内容。

结构化观测至少记录：

- 数据源和获取方式；
- 观测对象和空间范围；
- 数据产生时间、获取时间和最后成功时间；
- 数值、单位和采样间隔；
- 缺测、延迟、精度和覆盖范围；
- 所用基线和比较窗口；
- 能回答的主张和不能回答的问题。

### 4.3 时间和空间范围

本案例使用三个时间窗口：

- 6 小时：判断消息出现后是否有即时行动或市场反应。
- 24 小时：判断暂停是否保持，外交表态是否得到后续行动配合。
- 72 小时：判断局部降温是否转为较稳定状态，外围战线是否出现反向变化。

空间上分三层记录：

- 核心区：伊朗及与美伊直接行动有关的区域。
- 通航区：霍尔木兹海峡、阿曼湾、红海和相关主要航路。
- 外溢区：黎巴嫩、也门等可能影响整体判断的外围战线。

媒体或 GDELT 标出的地点只表示文章提到了该地。事件发生地需要从原文、通告或观测数据中确认。

## 5. 人工研判的工作组织

### 5.1 人员分工

小组作业可分为四类工作。一人可以兼任多项，但复核人应与主笔分开。

| 角色 | 主要工作 | 交付物 |
| --- | --- | --- |
| 任务负责人 | 确定问题、范围、时限和报告对象；批准最终判断 | 任务单、最终简报 |
| 信息收集人员 | 查找原文、保存快照、维护时间线和来源关系 | 来源台账、采集记录 |
| 专题分析人员 | 分析外交、军事活动、海事、航空、遥感、网络和市场数据 | 分析记录、异常说明 |
| 复核人员 | 检查引用、转载去重、矛盾、置信度和措辞边界 | 复核意见、发布确认 |

### 5.2 一轮人工研判的顺序

| 阶段 | 主要工作 | 完成条件 |
| --- | --- | --- |
| 接题 | 写清决策问题、AOI、6/24/72 小时时间窗、报告对象 | 任务范围没有歧义 |
| 拆题 | 把资讯拆成 C1 至 C8，列出 H1 至 H4 | 每项判断都有可核查条件 |
| 收集 | 查官方原文、原始报道和结构化观测 | 关键来源已保存；缺失项已登记 |
| 整理 | 统一时间、实体和地点，识别稿源和转载 | 时间线和来源关系可复核 |
| 分析 | 分别完成外交、行动、通航、航空、遥感、网络、市场分析 | 每项分析写明方法、结果和限制 |
| 核验 | 逐项判断支持、反驳、背景、重复或未知 | 主张核验表完成 |
| 研判 | 比较 H1 至 H4，给出主判断、备选判断和置信度 | 结论覆盖主要事实和矛盾 |
| 交付 | 形成简报、详细解读、预警和建议 | 引用可回查，复核人已确认 |
| 更新 | 监测触发条件，按 6/24/72 小时复评 | 新信息进入同一任务，不另起孤立结论 |

## 6. 各类数据如何分析

### 6.1 官方表态分析

官方材料先核对原文，再分析措辞。

1. 确认发言人身份、发布时间和场合。
2. 区分“暂停”“停止”“停火”“降低行动强度”和“为谈判留出空间”。这些词的约束力不同。
3. 提取前提条件、适用范围、有效时间和保留条款。
4. 比较美伊双方表述是否对称。美方暂停打击，不自动等同于伊方接受停火。
5. 查看斡旋方是否确认双方仍在沟通，是否给出会谈时间、议题或程序安排。
6. 检查后续行动是否与表态一致。

本案例中，媒体报道将美方暂停与外交空间联系起来；伊方消息人士的说法带有“只要美国维持暂停”的条件。分析时应保留这一条件。White House 和 USUN 尚未找到对应完整原文，当前只能写成“多家媒体转述美方官员表示”。

### 6.2 新闻报道和传播关系分析

新闻分析包含内容核对和稿源去重。

- Reuters 稿件被 Cyprus Mail、The Business Times 等媒体转载，按一个报道家族计算。
- AP 稿件被 Daily Breeze 等媒体转载，按一个报道家族计算。
- Punch、Channels Television、Free Malaysia Today 的同题内容高度相似，需要继续确认原始稿源。
- NPR、France 24、Al Jazeera、TASS、The National 可分别检查其采访、引语和编辑内容是否独立。

转载报道仍有价值。它可以说明信息扩散范围和不同地区的关注重点，但不会增加核心事实的独立来源数量。

分析人员还需检查标题与正文是否一致。例如，标题写“停火谈判加速”，正文可能只说明“信息交流持续”。报告只能采用正文能够支持的表述。

### 6.3 冲突和军事活动分析

本项关注区域活动是否与“暂停”一致，只做公开层面的事件统计和趋势判断。

- 建立事件时间线，记录打击、拦截、警报、公开行动声明及可信否认。
- 对每起事件标明首次报告时间、可能发生时间和确认状态。
- 区分美伊直接行动、盟友行动和代理人行动。
- 将“没有新报道”与“确认没有行动”分开。前者可能来自信息延迟或覆盖不足。
- 如有卫星影像，检查公开区域是否出现新增损伤或明显活动变化。单景影像只能说明该时点的状态，不能说明整个窗口内没有行动。

当前材料支持“美伊直接行动出现暂停”的媒体共识，但缺少完整的独立事件序列和遥感核验。对 C1、C2 可给阶段判断，对“实际行动完全停止”保留意见。

### 6.4 海事通航分析

海事分析需要把安全通告和船舶运行放在一起看。

- UKMTO/JMIC 用于确认事故、威胁通告、风险区域和发布时间。
- AIS 用于统计通过固定断面或 AOI 的独立船舶数、航速、等待时间、折返和绕行。
- 港口和航运公司通告用于确认暂停靠港、改道、保险或作业限制。
- 历史基线至少覆盖相同星期和相同时段，避免把日常波动当成异常。
- AIS 静默既可能来自安全考虑，也可能来自覆盖、设备或数据授权问题，不能单独解释为军事意图。

本案例尚未取得可持续使用的 AISStream 数据，UKMTO 页面在服务器请求中返回 403。现阶段不能判断霍尔木兹通航已经恢复，也不能用少量估算船舶数据支持这一结论。

### 6.5 航空活动分析

ADSB.lol 的区域接口返回某一中心点周边的当前快照。`26.5, 56.3` 是查询中心，`dist/250` 表示半径 250 海里。该接口不提供历史时间参数和最大返回条数参数。

人工分析需要按固定间隔保存快照，并完成以下处理：

- 剔除 `seen` 过大的旧观测；
- 按商业航班、通用航空和无法分类的目标分别统计；
- 比较航班数量、主要航路、高度带、绕行和返航；
- 使用相同中心、半径、时间段和采样频率；
- 对照过去 7 天或更长时间的同口径基线。

本轮两个不同时点的快照分别返回 109 架和 99 架。样本量变化可能来自时段差异、航班计划或数据覆盖，不能据此判断局势降温。

### 6.6 遥感和火点分析

遥感用于回答地面状态和跨期变化问题。

- 光学影像适合查看可见设施、船舶和损伤，受云量和光照影响。
- SAR 可在夜间和多云条件下工作，适合查看大型目标和地表变化，但解译难度更高。
- NASA FIRMS 提供热异常线索，需要排除炼化、火炬和其他常驻工业热源。
- 单景影像用于确认某一时点状态；T0、T1、T2 多时相影像用于识别变化趋势。

如果本案例后续取得连续影像，可把霍尔木兹通航相关港口和公开能源设施作为持续监测对象。分析人员需先选取冲突前或正常期影像作为 T0，再比较 T1、T2 的船舶密度、设施状态和热异常。该工作进入 PRD 场景二。

### 6.7 网络可用性分析

IODA 返回多个数据源的时间序列。GTR、Merit 和 Mozilla 的量纲、采样间隔和覆盖方式不同，不能直接横向比较。

人工分析按单一数据源建立基线：

1. 选取同一国家、同一数据源和同一采样间隔。
2. 计算过去 7 天或 30 天在相同时段的正常范围。
3. 检查当前窗口的持续偏离、缺测和恢复时间。
4. 用其他网络观测或官方通告确认异常是否真实。
5. 将全国性变化与局部服务故障分开。

本案例已取得伊朗在 7 月 26 日 16:00 至 22:00 UTC 的 GTR、Merit 和 Mozilla 数据。当前只有原始序列，尚未建立同源基线，因此不能判断是否出现与军事行动有关的全国性网络异常。

### 6.8 市场反应分析

市场数据用于判断外部参与者如何给风险定价，不直接证明军事和外交事实。

建议选择 WTI、Brent、黄金、白银、美股主要股指期货、VIX、美元指数、Bitcoin 和 Ethereum。对每项资产记录消息发生前后的价格、成交量、交易时段和合约信息。

分析时注意：

- 亚洲早盘流动性和欧美主交易时段不同；
- 油价还受库存、OPEC、宏观数据和美元影响；
- 加密资产和贵金属可能受其他风险事件驱动；
- 新闻发布时间可能晚于市场首次获知时间；
- 单个时点的涨跌不能说明反应持续。

本案例目前只有资讯中的“油价跳水、风险资产上涨”描述。FRED 能提供 WTI、Brent 和 VIX 的日频基线，但不能复核今晨盘中变化。C7 暂列未确认。

### 6.9 历史和地区背景分析

当前表态需要放入既有外交安排和外围战线中理解。阿曼外交部 6 月 23 日发布的联合声明说明，美伊之间已有谅解和霍尔木兹通航议题的工作安排；7 月 9 日、11 日和 14 日的阿曼公开材料继续讨论停止升级、政治解决和通航。

这些材料可以说明斡旋机制此前存在，不能代替 7 月 26 日的最新会谈确认。红海摩擦、胡塞相关行动、黎巴嫩条件和里海风险则构成反向背景，说明美伊直接降温可能与地区其他战线并存。

## 7. 如何进行交叉验证

### 7.1 先判断来源能证明什么

来源权威性要结合具体问题判断：

- White House 能权威说明美国政府的公开立场，不能单独证明伊朗实际行动。
- Iran MFA 能说明伊朗外交口径，不能单独证明美方意图。
- Reuters、AP 等通讯社可以提供采访和现场信息；匿名消息需保留身份不明带来的限制。
- AIS、ADS-B、影像和网络观测可以说明局部活动或状态，不能单独解释政治意图。
- 市场行情可以说明价格变化，不能证明变化由某一条消息导致。

### 7.2 判断来源是否独立

两条材料满足以下条件时，才可视为相对独立：

- 原始采访对象不同；
- 原始观测手段不同；
- 没有共同引用同一匿名消息或通讯社稿；
- 发布时间和内容显示并非简单转述；
- 关键事实来自各自获取的材料。

同一 Reuters 稿件被十家媒体转载，事实来源仍是一组。美方官方声明与 ADS-B 区域趋势属于不同来源类型，可以相互补充。

### 7.3 为每条材料标注作用

| 标记 | 含义 | 处理方式 |
| --- | --- | --- |
| 支持 | 直接支持主张的全部或部分内容 | 说明支持的是哪一部分，是否带条件 |
| 反驳 | 与主张直接冲突 | 核对时间、适用范围和来源可靠性后调整判断 |
| 背景 | 解释原因、环境或历史，不直接证明主张 | 不计入独立确认数量 |
| 重复 | 转述或转载已有材料 | 保留传播信息，不重复计数 |
| 未知 | 数据缺失、访问失败或含义不清 | 进入缺口清单，不推测补齐 |

### 7.4 本案例的主张核验表

| 主张 | 当前支持材料 | 反向材料或限制 | 当前判断 |
| --- | --- | --- | --- |
| C1 美国暂停打击 | NPR、France 24、Al Jazeera、AP 和 Reuters 报道家族均有相关描述 | 尚未取得当日 White House 或 USUN 完整原文；缺独立行动序列 | 较可信，置信度中高 |
| C2 伊朗同步暂停 | Reuters 匿名伊朗消息人士；NPR、AP 等报道双方连续第二天暂停 | 说法带有美方先停的条件；尚未取得 Iran MFA 对应原文 | 有条件成立，置信度中 |
| C3 沟通与斡旋继续 | 多家媒体转述；阿曼此前公开材料证明沟通机制存在 | 同日双方及斡旋方完整原文不足 | 较可能，置信度中 |
| C4 暂停用于外交 | 美方官员表态的多家媒体转述 | 库存、军事调整等其他原因未排除；TASS 报道对“库存不足”解释形成反向材料 | 外交是重要原因之一，不能认定为唯一原因 |

| C7 市场持续重新定价 | 今晨资讯描述了多资产变化 | 无合规盘中数据复核；可能受其他因素影响 | 无法确认 |
| C8 中东整体持续降温 | 美伊直接行动出现暂停 | 红海、胡塞、黎巴嫩条件及其他外溢风险仍在 | 当前不支持 |

### 7.5 处理矛盾

出现冲突时依次检查：

1. 两条材料是否描述同一时间段。
2. “暂停”“停止”和“停火”是否被翻译成了同一概念。
3. 一方描述的是公开政策，另一方描述的是实际行动，二者是否属于不同层面。
4. 事件是否发生在美伊直接战线，还是外围战线。
5. 转载报道是否被误认为多个独立来源。
6. 观测数据是否因覆盖、延迟或缺测出现假异常。

矛盾未解决时，报告写出双方说法和缺失材料。不要选取更符合预期的一方作为事实。

## 8. 如何形成研判

### 8.1 区分来源事实、事件事实、判断和预测

- **来源事实：** 可以确认某个来源发布了某项内容。例如，多个报道家族均称双方连续第二天未相互打击。
- **事件事实：** 有当事方原文、权威通告或直接观测支持的事件。例如，某一时段发布了正式暂停声明，或固定区域观测记录显示活动已经变化。
- **判断：** 对多项材料的解释。例如，当前状态更接近条件性互停。
- **预测：** 对未来状态的估计。例如，未来 24 小时互停较可能延续。

报告中四类内容分段书写。来源事实不能直接写成事件事实。预测必须附带触发条件和失效条件。

### 8.2 比较不同解释

对 H1 至 H4 逐项检查：

| 观察结果 | H1 外交降温 | H2 条件性互停 | H3 战术性停顿 | H4 局部降温、地区外溢 |
| --- | --- | --- | --- | --- |
| 双方连续第二天暂停直接行动 | 支持 | 支持 | 支持 | 支持 |
| 伊方表态带有“美方先停”条件 | 部分不利 | 强支持 | 支持 | 中性 |
| 沟通和斡旋仍被多家报道提及 | 支持 | 支持 | 部分不利 | 中性 |
| 同日一手官方原文不完整 | 不确定 | 不确定 | 不确定 | 不确定 |
| 红海和其他外围风险仍存在 | 不利 | 支持 | 支持 | 强支持 |
| 通航、航空和市场缺少连续验证 | 不确定 | 不确定 | 不确定 | 不确定 |

当前材料最符合 H2，并同时支持 H4。H1 仍有可能，需要正式会谈安排和持续的行动数据增强。H3 尚不能排除，需要观察军事准备、通航高风险通告和暂停持续时间。

### 8.3 置信度口径

| 等级 | 使用条件 | 写法 |
| --- | --- | --- |
| 高 | 有一手原文或直接观测，且至少一类独立材料一致，无重要矛盾 | “已确认”“高度可信” |
| 中高 | 多个独立报道家族一致，关键细节基本吻合，但仍缺部分一手或行动材料 | “较可信”“多项材料一致显示” |
| 中 | 有支持材料，也存在条件、匿名来源或未解决矛盾 | “较可能”“现有材料倾向于” |
| 低 | 支持材料有限，反向材料较强，或外推范围过大 | “可能性较低”“当前材料不支持” |
| 不足 | 缺少关键数据，无法作出方向性判断 | “尚无法判断” |

置信度针对具体主张，不给整篇报告设置一个笼统分数。材料增加后可以上调，也可以因新矛盾下调。

### 8.4 本案例当前判断

截至 7 月 27 日 16:00 CST，可形成以下判断：

1. **美伊直接军事行动处于短期相互暂停状态，置信度中高。** 多个相对独立的报道家族描述双方连续第二天暂停行动。美方当日完整官方原文和独立行动序列仍需补充。
2. **伊方暂停带有明确条件，置信度中。** 现有说法强调美国维持暂停，伊方对美方意图仍有怀疑。
3. **外交沟通仍在进行的可能性较高，置信度中。** 媒体报道与阿曼此前公开的斡旋机制方向一致，但同日一手材料不完整。
4. **当前更接近条件性互停，并伴随地区外溢风险。** 红海、胡塞及其他外围条件仍可能打断这一状态。
5. **通航、航空和市场是否已持续改善，尚无法判断。** 相关连续数据未补齐。

### 8.5 未来 24 至 72 小时判断

未来 24 小时，双方继续维持直接行动暂停的可能性较高。支持因素包括多家报道的一致描述和仍在运作的沟通渠道。主要风险是任一方对对方行动作出不同解释，或外围战线发生造成伤亡的事件。

未来 72 小时能否形成较稳定降温，取决于三项变化：双方是否发布更明确的正式表态；斡旋方是否公布会谈进展；通航和实际活动是否持续改善。缺少其中两项时，不宜将短暂停顿写成稳定停火。

## 9. 如何输出情报产品

### 9.1 快速情报简报的结构

快速简报供决策者在几分钟内阅读，建议控制在一页：

1. 标题、时间截点和关注区域。
2. 核心判断及置信度。
3. 已确认事实。
4. 主要影响。
5. 关键不确定项。
6. 未来 24 至 72 小时观察点。
7. 当前预警状态和建议。
8. 主要来源。

### 9.2 本案例快速简报样例

#### 美伊直接行动出现条件性暂停，地区外溢风险仍在

**时间截点：** 2026 年 7 月 27 日 16:00 CST

**核心判断：** 多个独立报道家族显示，美伊已连续第二天暂停直接军事行动。伊方暂停以美国继续停止打击为条件。当前状态接近条件性互停，尚未形成稳定停火。置信度：中高。

**已确认和较可信事项：**

- NPR、France 24、Al Jazeera、AP 和 Reuters 报道家族均提到双方暂停直接行动。

- 多家报道提到信息交流和第三方斡旋仍在继续。
- 阿曼此前已公开持续推动美伊沟通和霍尔木兹通航安排。

**主要影响：**

- 美伊直接冲突的短期升级风险有所回落。
- 霍尔木兹通航是否实际改善仍缺 AIS 和 UKMTO/JMIC 数据。
- 红海和其他外围战线仍可能造成地区风险反复。
- 今晨油价和风险资产的反应尚未取得盘中行情复核。

**未来 24 至 72 小时观察点：**

- 美伊是否发布正式、对称的暂停声明。
- 斡旋方是否公布会谈时间或新的程序安排。
- 是否出现新的直接打击、重要商船事件或大范围民航绕行。
- 油价风险溢价是否在欧美交易时段继续回落。

**当前建议：** 维持较高关注，不立即下调霍尔木兹和红海业务风险措施。优先补齐一手表态、通航和盘中行情数据，并在 6 小时后更新判断。

### 9.3 详细解读的结构

详细解读面向分析人员和业务负责人，建议包含：

- 任务背景和决策问题；
- 事件时间线；
- 各方正式立场；
- 来源关系和独立性说明；
- 海事、航空、遥感、网络和市场分析；
- 竞争性解释比较；
- 当前判断和置信度；
- 影响评估；
- 预警状态；
- 后续收集计划；
- 主要来源和数据限制。

### 9.4 本案例详细解读摘要

本次降温信号首先出现在媒体报道和市场叙事中。媒体报道的一致部分是：美伊直接行动连续第二天暂停，双方仍通过第三方保持沟通。伊方说法附带对等条件，因此当前状态缺少无条件停火的特征。

外交解释有一定基础。阿曼在 6 月和 7 月持续公开美伊沟通及霍尔木兹通航议题。不过，7 月 26 日美伊双方和斡旋方的完整原文仍未补齐。库存压力、战术调整和盟友协调等解释也未完全排除。

行动层面的确认较弱。当前没有完整的冲突事件序列、AIS 连续数据和多时相影像。ADSB.lol 只有两个不同时间的区域快照，不能证明航空恢复。IODA 有原始数据，但缺少同源历史基线。市场反应也只有二手描述。

综合现有材料，条件性互停是最合理的解释。地区整体风险没有同步消失。红海、胡塞、黎巴嫩条件和霍尔木兹通航安排仍可能影响后续走势。未来 72 小时的判断重点应放在正式表态、会谈安排和实际活动变化上。

## 10. 如何形成预警

### 10.1 预警对象

本案例需要同时监测两个方向：

- **升级预警：** 暂停被打破，直接冲突或外围风险上升。
- **降温确认：** 正式表态、实际活动和市场风险同时改善，短期暂停转为较稳定状态。

只监测升级会遗漏重要转折；只监测降温会产生确认偏差。

### 10.2 预警等级

| 等级 | 适用情况 | 输出要求 |
| --- | --- | --- |
| 关注 | 出现单一可信线索，或重要信息尚缺独立确认 | 说明线索、缺口和复查时间 |
| 预警 | 一手材料与另一类独立来源一致，或两类独立观测同时异常 | 说明影响范围、置信度和处置建议 |
| 紧急 | 已确认重大行动、重要通航事件或多项指标快速恶化 | 立即通知，列出已确认事实和短时行动要求 |

阈值应按数据源基线校准。AIS 船舶数下降、ADS-B 航班减少或油价上涨都不能直接使用固定比例作为通用阈值。分析人员先观察正常波动，再确定适合该 AOI 和时段的阈值。

### 10.3 本案例监测指标

| 方向 | 触发条件 | 需要的确认 | 触发后的处理 |
| --- | --- | --- | --- |
| 暂停被打破 | 美伊任一方宣布恢复行动，或出现新的直接打击 | 一手声明、权威通告或两个独立报道家族 | 立即重评 C1、C2，发布升级预警 |
| 谈判受阻 | 任一方否认沟通、斡旋方宣布中断、附加条件明显扩大 | 当事方或斡旋方原文 | 下调 H1，提高 H2/H3 权重 |
| 海峡风险上升 | UKMTO/JMIC 新重大事件，AIS 显示持续大范围绕行或等待 | 通告与 AIS 趋势相互印证 | 更新航运影响，通知相关业务负责人 |
| 航空风险上升 | 多家航空公司改道，固定 AOI 航班持续低于基线 | ADS-B 趋势与航司/机场公告 | 更新人员出行和航空运营风险 |
| 网络异常 | IODA 同源指标持续偏离基线，其他观测同时异常 | 第二类网络观测或官方通告 | 评估信息获取和当地运营影响 |
| 市场风险反转 | 油价、VIX 等在主要交易时段持续上升 | 多资产、跨时段数据 | 更新能源和供应链风险说明 |
| 降温得到加强 | 双方正式声明、斡旋进展、通航与航空指标共同改善 | 至少一项一手材料和一项行动数据 | 上调 H1，评估是否降低预警等级 |

### 10.4 当前预警状态样例

**名称：** 美伊条件性互停持续性观察

**等级：** 关注

**依据：** 多个报道家族一致描述双方暂停直接行动；伊方说法带有对等条件；同日一手原文和行动数据不完整。

**有效期：** 6 小时，或出现新的直接行动和正式声明时立即重评。

**重点监测：** 美伊正式发布、阿曼等斡旋方公告、UKMTO/JMIC、固定 AOI 的 AIS/ADS-B 趋势、主要市场盘中行情。

## 11. 如何提出下一步行动建议

行动建议需要说明对象、时限、触发条件和复核方式。建议分为情报收集、业务风险和持续监测三类。

### 11.1 情报收集建议

| 优先级 | 动作 | 完成标准 |
| --- | --- | --- |
| 高 | 查找 White House、USUN 对华尔兹表态的原文、视频或逐字稿 | 明确说话时间、场合、原文和适用范围 |
| 高 | 查找 Iran MFA 对巴加埃表态的原文 | 区分官方立场与匿名消息人士说法 |
| 高 | 获取阿曼等斡旋方 7 月 26 日后的最新公告 | 确认沟通是否持续及下一步安排 |
| 高 | 获取 UKMTO/JMIC 最新通告和连续 AIS 数据 | 判断海峡通航是否实际改善 |
| 中 | 每 15 至 30 分钟保存同一 AOI 的 ADSB.lol 快照 | 形成至少 24 小时可比序列 |
| 中 | 获取合规盘中市场行情 | 完成消息前后 6/24 小时事件窗口分析 |
| 中 | 为 IODA 建立 7/30 天同源基线 | 判断伊朗网络是否出现异常偏离 |
| 中 | 申请 NASA FIRMS key 并准备常驻工业热源清单 | 避免将常态热源误报为新事件 |

### 11.2 业务风险建议

- 航运和能源业务继续执行现有高风险区域监测与报告要求。通航数据未确认前，不因单条降温消息取消必要的风险控制。
- 在霍尔木兹、阿曼湾和红海有人员、船舶或供应链暴露的单位，复核未来 72 小时计划、保险限制、改道条件和通信安排。
- 市场和采购判断采用经复核的盘中数据。二手资讯中的价格描述只作为线索。
- 对外发布使用“条件性暂停”“短期降温信号”等有限表述，并注明时间截点。避免使用“局势已恢复稳定”。
- 出现新打击、重要商船事件或斡旋中断时，立即重新评估相关业务安排。

### 11.3 转入场景二的持续监测建议

本轮完成后，可为公开港口、航道和能源基础设施建立持续监测任务：

1. 确定 AOI 和业务关注对象。
2. 选择冲突前或正常期的 T0 影像。
3. 规定光学和 SAR 的复看频率、质量要求和补采条件。
4. 对 T1、T2 影像记录船舶密度、设施状态、活动痕迹和热异常。
5. 变化达到阈值后生成场景二预警，并回到场景一查找官方和 OSINT 解释。

这项工作用于持续发现变化。首次任务需由分析人员人工确定 AOI、基准和判读规则，后续再评估哪些步骤适合自动化。

## 12. 质量检查

### 12.1 发布前检查表

- 任务问题、AOI、时间窗和报告对象已经明确。
- 每项主要判断都能对应到原始材料或观测记录。
- Reuters、AP 等转载家族已经去重。
- 事实、判断和预测分开书写。
- 官方立场没有被当作对方行动的直接证明。
- “没有报道”没有被写成“确认没有发生”。
- GDELT 地点已经过原文复核。
- ADS-B、AIS、IODA 和市场数据使用相同口径的历史基线。
- 反向材料和未解决矛盾已经写入报告。
- 置信度针对具体主张，且写明上调和下调条件。
- 预警包含有效期、触发条件和复查时间。
- 行动建议说明对象、时限和复核方式。
- 精确军事位置和进攻性建议已经排除。

### 12.2 当前缺口

本案例仍需补充：

1. 美方和伊方当日完整官方原文。
2. 斡旋方在同一时段的最新公告。
3. 可复核的冲突事件序列。
4. AIS 连续数据及 UKMTO/JMIC 通告。
5. 固定 AOI 的 ADS-B 连续基线。
6. 影像和 FIRMS 数据。
7. IODA 同源历史基线。
8. 合规盘中市场行情。

这些缺口不会阻止发布阶段简报，但会限制对通航恢复、实际行动完全停止和持续降温的判断。

## 13. 后续技术实现评估的输入

团队应先按本文方法人工完成一次完整任务，并保存实际工作记录。技术评估以这些记录为依据，检查哪些步骤耗时、容易出错或需要持续运行。

### 13.1 适合优先自动化的工作

- 官方 RSS、新闻和公开接口的定时采集；
- 时间、地点、人物和机构的标准化；
- Reuters、AP 等转载关系识别；
- 主张与材料的初步关联；
- ADS-B、AIS、IODA、FIRMS 和市场数据的时间窗对齐；
- 历史基线计算和异常提示；
- 预警条件监测；
- 简报初稿和引用目录生成。

### 13.2 需要分析人员确认的工作

- 决策问题和任务范围；
- 来源能证明什么；
- 同源报道是否独立；
- 矛盾材料的解释；
- 竞争性假设比较；
- 置信度调整；
- 意图和影响判断；
- 预警发布和行动建议批准。

### 13.3 技术实现的最小业务对象

| 对象 | 必要内容 |
| --- | --- |
| 任务 | 决策问题、AOI、时间窗、负责人、更新时间 |
| 主张 | 主体、行为、对象、条件、时间、地点 |
| 来源 | 发布机构、作者、URL、发布时间、获取时间、来源类型 |
| 材料 | 原文、数据快照、完整性、质量和适用范围 |
| 来源关系 | 原创、引用、转载、共同稿源 |
| 观测 | 对象、数值、单位、空间范围、数据时间、获取时间、缺测状态 |
| 核验结果 | 支持、反驳、背景、重复、未知及说明 |
| 研判 | 结论、置信度、主要依据、矛盾和缺口 |
| 预警 | 等级、触发条件、有效期、复查时间和接收对象 |
| 报告 | 版本、时间截点、简报、详细解读、引用和审核记录 |

技术方案至少要复现人工过程中的来源去重、时间对齐、核验状态、判断依据和更新记录。只聚合新闻数量或生成摘要，无法完成本案例所需的研判。
