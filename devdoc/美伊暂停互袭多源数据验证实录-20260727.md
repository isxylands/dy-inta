AP 提供了美方、伊方、斡旋方和海事活动四个角度。部分信息仍来自匿名官员或二次转述，需要在报告中保留来源层级。

### 5.2 UKMTO/JMIC 实测

#### 需要取得的数据

UKMTO 和 JMIC 的材料分别解决两个问题：

- UKMTO Warning/Recent Incidents 用于核对单次事件，字段包括事件编号、报告和发布时间、来源、事件类型、相对位置、船型、损伤、人员和环境影响，以及后续状态更新。
- JMIC Advisory Note/Weekly Dashboard 用于判断一段时间内的海事态势，内容包括区域威胁等级、最近 48/72 小时事件、商船流量和锚地拥堵、航路变化、GNSS 干扰及安全建议。

要复核 AP 所述“72 小时没有新确认攻击”和“商船流量处于三周低位”，需要取得覆盖 7 月 24—27 日的 JMIC Advisory Note，并核对同一时段 UKMTO Warning 编号是否连续、有无更新或撤回。

`https://www.ukmto.org/recent-incidents` 可在普通 Chrome 中打开。页面列表由客户端加载，自动化接管该 Chrome 标签页时连续超时，未能读取其网络请求。服务器侧 `curl` 本轮被 Cloudflare 拦截；此前曾取得只含 `0 reports` 的服务端页面。两种结果都不能用来判断是否发生事件。

#### 更稳妥的获取方式

[UKMTO 官网](https://www.ukmto.org/)明确提供邮件订阅，申请人填写姓名、邮箱和公司后，经批准可接收海事安全通告。当前未发现 UKMTO 对外发布的稳定 API 或 RSS。建议采用以下顺序：

1. 使用项目专用邮箱申请 UKMTO Maritime Security Alerts。邮件正文或附件中的 Warning、Advisory Note、Weekly Dashboard PDF 作为主数据源。
2. 收到邮件后保存原始邮件时间、主题、附件哈希和官方 PDF 地址。PDF 按事件编号、时间、类型、位置、船型、影响和更新状态抽取结构化字段。

## 6. 区域航空数据验证

### 6.1 同一接口、同一半径横向比较

[ADSB.lol 交互文档](https://api.adsb.lol/docs)将以下接口定义为“中心点周边、最大 250 海里范围内的航空器”。经纬度是中心点，`250` 是半径。接口参数只有 `lat`、`lon` 和 `radius`，没有历史时间和最大返回条数参数。

```text
https://api.adsb.lol/v2/lat/26.5/lon/56.3/dist/250
```

7 月 27 日的两个霍尔木兹快照分别返回 93 架和 88 架。7 月 28 日进一步选取曼德海峡、马六甲海峡和直布罗陀海峡作为对照。四个查询使用相同 250 海里半径，并在一分钟内完成两轮采样：

| 区域及中心点 | 第一轮总数 / 新鲜目标 | 第二轮总数 / 新鲜目标 | 第二轮地面 / 空中 | 第二轮低于 10,000 英尺 / 高于 25,000 英尺 |
| --- | ---: | ---: | ---: | ---: |
| [霍尔木兹及海湾沿岸 `26.5,56.3`](https://api.adsb.lol/v2/lat/26.5/lon/56.3/dist/250) | 109 / 101 | 112 / 100 | 20 / 91 | 31 / 34 |
| [曼德海峡 `12.6,43.4`](https://api.adsb.lol/v2/lat/12.6/lon/43.4/dist/250) | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 |
| [马六甲海峡 `1.35,103.8`](https://api.adsb.lol/v2/lat/1.35/lon/103.8/dist/250) | 43 / 38 | 40 / 38 | 0 / 40 | 10 / 12 |
| [直布罗陀海峡 `36.0,-5.5`](https://api.adsb.lol/v2/lat/36.0/lon/-5.5/dist/250) | 25 / 23 | 28 / 27 | 9 / 19 | 3 / 12 |

“新鲜目标”指 `seen <= 15` 秒。采样时间为 2026 年 7 月 28 日约 12:22 CST。

这组对照支持三个判断：

1. 霍尔木兹样本中的当前可见航空活动较充分。两轮均超过 100 架，高于马六甲和直布罗陀样本；同时存在地面、低空和高空目标，不符合该 250 海里圆形范围内航空活动普遍停摆的表现。
2. 曼德海峡连续返回 0，不能解释为“没有飞机”。同一免费数据网在不同地区的接收覆盖差异很大。这也说明霍尔木兹当前非零结果有观察价值，但跨区绝对数量不宜直接用于排名航空繁忙度。
3. 每个 250 海里圆都会覆盖机场、沿岸城市和部分内陆空域，统计对象并非只穿越海峡的航班。横向对照可以识别异常空白和大致活动水平，不能代替航路级统计。

### 6.2 第二数据源交叉检查

[OpenSky Network 当前状态接口](https://openskynetwork.github.io/opensky-api/rest.html#all-state-vectors)支持用经纬度矩形查询。2026 年 7 月 28 日 12:29 CST，在 `23—28.5°N, 52—61°E` 同一目标区内，OpenSky 返回 77 架；约 10 秒后，从 ADSB.lol 250 海里结果中按同一矩形过滤得到 105 架，其中 89 架 `seen <= 15` 秒。

两个独立的众包 ADS-B 网络同时检测到数十架至百余架航空器，能够相互支持“目标区域当前并未大范围关闭”。数量不一致主要受接收站覆盖、合并规则、更新时间和目标过滤方式影响，不能把差值解释为航空器增减。

### 6.3 本项结论

现有证据可以回答“当前是否仍有较多航空器活动”，答案是肯定的。它不能回答“暂停后是否恢复、恢复了多少”。该问题需要连续保存当前快照，并取得暂停前至少 7 天的同区域、同时段基线；同时要按航路、机场起降和过境目标拆分，避免把圆形范围内的地面目标混入过境流量。

## 7. 遥感和热异常数据验证

### 7.1 取数范围和方法

本轮使用有效 `MAP_KEY` 调用 [NASA FIRMS Area API](https://firms.modaps.eosdis.nasa.gov/api/area/)，取得 `VIIRS_SNPP_NRT`、`VIIRS_NOAA20_NRT` 和 `VIIRS_NOAA21_NRT` 三套近实时数据。查询分为两层：

- 大范围：`44—64°E, 23—40°N`，用于检查伊朗及海湾周边是否出现异常激增。
- 海峡周边：`52—61°E, 23—28.5°N`，从大范围结果中筛选，用于检查霍尔木兹及海湾沿岸变化。

基线扩展为 6 月 26 日至 7 月 25 日，暂停后窗口为 7 月 26—27 日。[接口说明](https://firms.modaps.eosdis.nasa.gov/api/area/)规定单次 `DAY_RANGE` 为 1—5 天，因此按 5 天分段请求。S-NPP 的 7 月 11—15 日查询只返回表头，该传感器基线实际覆盖 25 天；NOAA-20、NOAA-21 覆盖 30 天。缺失窗口按“未取得数据”处理，没有记为零。

7 月 28 日查询当日数据时，接口鉴权成功但只有表头；[数据可用性接口](https://firms.modaps.eosdis.nasa.gov/api/data_availability/)显示三套 VIIRS 近实时源最新日期均为 7 月 27 日。因此本文不对 7 月 28 日作“没有热异常”的判断。7 月 27 日的 S-NPP 数量也从 09 时查询时的 140 / 10 更新为 12 时查询时的 193 / 16，说明近实时数据会补录，记录必须带 `as_of` 时间。

### 7.2 海峡周边观测结果

| 传感器 | 基线有效天数 | 基线日均火点 / 中位数 | 基线日均高置信 / 中位数 | 7 月 26 日火点 / 高置信 | 7 月 27 日火点 / 高置信 |
| --- | ---: | ---: | ---: | ---: | ---: |
| S-NPP | 25 | 236.9 / 196 | 18.4 / 3 | 106 / 1 | 193 / 16 |
| NOAA-20 | 30 | 226.3 / 183.5 | 17.7 / 4 | 135 / 1 | 101 / 0 |
| NOAA-21 | 30 | 214.5 / 186.5 | 17.0 / 4.5 | 249 / 42 | 160 / 12 |

进一步按位置和辐射功率检查：

- 按 `0.1° × 0.1°` 网格匹配，暂停后共有 6 个高置信位置得到至少两颗卫星共同确认；6 个位置在 30 天基线中都已出现，没有新增的跨卫星高置信位置。
- 按更细的 `0.05° × 0.05°` 网格比较单颗卫星，S-NPP、NOAA-20、NOAA-21 暂停后分别有 8、1、14 个高置信网格。绝大多数在基线期已有高置信记录；没有出现由两颗以上卫星共同确认的新位置。
- 将暂停后网格的火辐射功率（FRP）与其 30 天历史最大值比较，S-NPP 和 NOAA-20 没有超过历史最大值；NOAA-21 有 1 个网格略高于历史最大值，但未达到其 1.5 倍，也没有获得跨卫星“新位置”确认。
- 三颗卫星的单日总量并不同步：7 月 26 日 NOAA-21 高置信点较多，而另外两颗很少。卫星过境、云层、昼夜和观测覆盖会显著影响计数，不能把单星单日变化直接解释为军事活动变化。

### 7.3 本项结论

补充第三颗卫星和 30 天基线是必要的。五天基线容易把常驻工业热源误判为新增异常，也无法识别近实时补录。扩展后未发现暂停后新增的跨卫星高置信位置，也未发现明显超出网格历史峰值的 FRP 激增。这一结果与“直接行动暂缓”方向一致，只能作为弱支持。

FIRMS 记录的是热异常。油气田火炬、炼化生产、工业火灾、农业焚烧和自然火灾都会产生记录；小规模、短时、被云层遮挡或未赶上过境时段的事件也可能漏检。下一步不应继续无差别扩大 FIRMS 区域，而应把 6 个跨卫星位置与油气、炼化、工业设施和常驻火点清单匹配；只对无法解释或显著偏离基线的候选点调取 [Copernicus Data Space](https://dataspace.copernicus.eu/analyse/apis/catalogue-apis) 的 Sentinel-1 SAR、Sentinel-2 光学影像。当前不能据 FIRMS 断言没有局部打击或没有设施损伤。

3. 美方希望为谈判留出空间较可信。伊方当天否认寻求恢复对美和谈，能够确认的是阿曼参与的海峡技术磋商仍在进行。
4. AP 所述“过去 72 小时没有新确认海上攻击”得到 NAVAREA IX 当前警告的方向性支持：7 月 24—27 日未发现新增同类安全事件警告。7 月 20、21 日两起油轮事件仍列在有效警告中，商船低流量、封锁、改道、登检和掉头事件说明通航风险没有恢复常态。
5. 市场已经明显降低部分冲突风险定价。WTI、Brent、股指期货和 VIX 的方向相互印证，报道中的精确最低价仍需合规行情源复核。
6. FIRMS 三颗卫星和 30 天基线没有显示暂停后出现新增的跨卫星高置信热异常位置，能够给“直接行动暂缓”提供弱支持。该数据不能排除局部打击，也不能用于判断设施损伤。
7. ADSB.lol 和 OpenSky 均显示霍尔木兹周边当前有较多航空器活动，同口径样本高于马六甲和直布罗陀对照区。没有暂停前基线，仍不能将其表述为“航空恢复”。AISStream 在欧洲对照区有数据、霍尔木兹短样本无数据，说明免费源的区域覆盖必须单独验证。

当前预警口径可调整为：

> 美伊直接行动维持条件性暂停，短期升级风险下降；正式和谈尚未确认，霍尔木兹航运限制仍在。维持关注等级，暂不下调航运和地区运营风险措施。新直接攻击、海峡重大事件或正式谈判安排出现时立即更新。

## 13. 可继续补充的佐证渠道

新增数据源应围绕未闭合的主张选择。优先补“能改变结论”的证据，不追求把来源数量做大。

| 优先级 | 数据渠道 | 开源获取方式 | 能补强的判断 | 使用限制和建议 |
| --- | --- | --- | --- | --- |
| P0 | [NAVAREA IX 航行警告](https://hydrography.paknavy.gov.pk/navarea-ix-warnings/) | 公开 HTML 和逐条 TXT，无 key | 海峡、阿曼湾新增航行危险；警告是否仍有效或已撤销 | 已实测可用，立即定时采集；它不是完整冲突事件库，不能单独证明“无事件” |
| P0 | [富查伊拉港航海通告](https://fujairahport.ae/marine-centre/notice-to-mariner/)和[每日船舶清单](https://www.fujairahport.ae/daily_shipping_list_print.cfm) | 港口公开网页和 PDF | 核对关键港口限制、到离港和锚地运行，补 AIS 区域覆盖缺口 | 先实测更新频率和历史保留期；再扩展至阿联酋、阿曼其他关键港口和码头 |

| P0 | [IODA](https://api.ioda.inetintel.cc.gatech.edu/v2/) | 公开 API | 国家或地区互联网可达性下降，辅助识别通信中断、断网或大范围基础设施影响 | 网络异常原因很多，需与 Cloudflare、运营商公告和事件时点交叉验证 |
| P0 | 官方网页、RSS、视频和记者会实录 | White House、USUN、Iran MFA、IRNA、Oman MFA 等公开渠道 | 精确核对暂停范围、条件、谈判状态和反向表态 | 保存原文、发布时间和发布主体；媒体转述与逐字稿分层 |
| P0 | GDELT DOC 2.0 | 公开 API，需控制请求频率 | 发现跨语种报道、反证和传播链 | 用于发现，不把同题转载数当独立来源数 |

| P1 | [FAA NOTAM Search](https://notams.aim.faa.gov/notamSearch/)及各国航空情报服务 | 公开查询页面；部分批量服务需注册或授权 | 核对空域关闭、航路限制、机场运行和危险区，解释 ADS-B 航路变化 | NOTAM 说明限制条件，不代表实际航班量；需与 ADS-B、机场到离港记录配合 |

| P1 | [Cloudflare Radar Outages](https://developers.cloudflare.com/radar/investigate/outages/) | 申请 API token | 与 IODA 交叉验证国家级、区域级网络中断 | 不能直接归因于军事行动；需要时空和官方公告佐证 |
| P1 | [ACLED API](https://acleddata.com/acled-api-documentation) | 注册账户、申请 key | 补充经编码的冲突事件时间线、参与方和地点 | 存在报道和编码时延，且底层仍可能来自新闻；不可与原新闻当作完全独立证据 |
| P1 | [NGA Maritime Safety Information](https://msi.nga.mil/NavWarnings) | 公开航行警告网页 | 补 NAVAREA IX 相邻区及特别警告，检查封锁、危险区和军事演训通告 | 与各 NAVAREA 协调方可能重复，需按警告编号去重 |
| P1 | [EIA Open Data](https://www.eia.gov/opendata/documentation.php) | 免费 API key | 排查库存、产量和供应变化是否构成油价的替代解释 | 多为日频或周频，不能替代交易所盘中行情 |
| P2 | 稳定商业 AIS 和港口事件数据 | 采购试用或已有集团数据服务 | 量化霍尔木兹实际通航量、等待、掉头、目的港和暗船行为 | 免费 AISStream 已证实区域覆盖不足；这是海事流量结论的首要付费补口 |
| P2 | 商业高分辨率光学和 SAR 影像 | 采购任务或存档影像 | 对重点设施、船舶和疑似损伤做更精细的前后对比 | 只对已形成证据线索的候选区采购，控制成本并遵守许可范围 |
| P2 | CME、ICE 或合规金融行情 | 采购或复用已有行情服务 | 复核精确最低价、成交量、消息前后分钟级反应 | Yahoo 只用于原型抽样，正式简报中的精确价格应回到合规源 |

最快形成证据闭环的组合是：NAVAREA IX 与 UKMTO/JMIC 邮件确认海事事件，商业 AIS 或可靠港口数据量化通航，ADSB.lol 与 OpenSky 共同建立航空序列，FIRMS 先筛候选点、Copernicus 再做目标级核验，IODA 与 Cloudflare 检查通信影响，交易所行情与 EIA 数据区分市场反应和供需替代原因。每类结论至少保留一个原始观测源和一个不同机制的复核源。
