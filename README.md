# DY-INTA 多源情报分析平台需求与方案工作区

`dy-inta` 是“多源情报分析平台”需求、评估和方案设计的文档工作区。当前仓库不是运行系统，也不是 `gintbroker` 的源码副本；它用于沉淀 PRD、现有项目适配分析、面向阿联酋/海湾客户的演示场景、本体与数据建设方案。

## 当前定位

核心判断：

- PRD v6.0 要建设的是“一级异常预警（L1）→ 二级验证确认（L2）→ 三级融合报告（L3）”情报生产系统。
- 被评估项目 `gintbroker` 更像“多源开源情报/遥测地图底座 + 人工智能操作面 + 雷达异常图层”，可以作为展示层和数据接入底座复用，但还不是完整 L1→L2→L3 情报生产闭环。
- 面向阿联酋或海湾地区客户，演示叙事应聚焦海上通道安全、关键基础设施韧性、开源情报降噪、多源验证和误判降级，不应做进攻型打击目标演示。

## 当前建议主线

4 个演示场景都值得保留，但不建议工程上做成 4 套烟囱。推荐整理成两条主线、四个能力包：

| 主线 | 能力包 | 价值 |
| --- | --- | --- |
| 海上通道安全 | 霍尔木兹/阿曼湾商船安全、导航完整性诊断 | 展示船舶自动识别、海事通告、导航干扰、雷达卫星核验和通行风险报告 |
| 关键基础设施影响评估 | 区域安全事件信息降噪、关键基础设施韧性监测 | 展示开源情报降噪、火点/遥感验证、设施损伤恢复、民用影响评估 |

底层应优先建设一套共同本体和工作流：

```text
观测记录 → 情报事件 → 证据关系 → 验证矩阵 → 情报报告 → 持续监测任务
```

## 文档原则

- 中文名优先；首次出现关键英文术语时给中英文对照。
- 结论先行，但必须保留证据和不确定性。
- 明确区分“当前项目已具备”“可复用”“缺口”“建议新增”。
- 面向阿联酋/海湾客户时，坚持民用保护、风险降级和连续监测叙事。
- 不输出实时打击目标、武器发射点推断、精确军事部署坐标或进攻性行动建议。
