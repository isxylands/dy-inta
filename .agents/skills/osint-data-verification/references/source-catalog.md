# 本项目数据源查询与查证目录

## 使用说明

本目录回顾截至 2026-08-05 的项目对话和已落盘查证材料。状态分为：

- `实际查询`：曾调用接口、读取页面/文件或检查返回结果；不表示当前仍可用。
- `实现审计`：只在相邻运行仓代码或外部资料中确认过接入实现，没有在本案例中重新查询数据。
- `失败/待接入`：尝试过但未取得可用事件数据，或仅列为后续候选。

任何时效性、配额、许可、字段或接口行为都必须当次复核。

## 7. 内网保存的航迹数据

详细查询合同见 `trajectory-query-playbook.md`。本 skill 的内部航迹查询面只保留一条：

- 195 环境航迹数据工作台 SQLite：`dy-track-explorer` 的已采集快照；实际用于三事件的窗口聚合、对象下钻、字段质量和入库延迟复核。优先使用其只读 API，复杂聚合才使用明确只读的 SQLite 连接或一致性只读副本。

该工作台不能称为“官方航迹数据”。上游提供方、原始采集链、许可、覆盖和知识截止时间仍需单独审计。不要把其他历史载体自动加入查询范围；用户若明确指定新的已授权内部数据源，应先单独确认权限、用途和查询合同，再决定是否扩展本 skill。

## 8. 只做过实现审计的相邻项目来源

`gintbroker`/Shadowbroker 的 WorldMonitor 对照中还确认了以下实现或数据面，但没有在 `dy-inta` 事件查证中逐一重跑：

- 新闻与冲突：RSS packs、LiveUAMap、DeepState、EUvsDisinfo、CrowdThreat。
- 航空航天：CelesTrak/TLE、Plane-Alert、航路与机场静态库。
- 灾害环境：USGS、GDACS、NOAA/NWS、RainViewer、OpenAQ、Smithsonian GVP、WastewaterSCAN。
- 交通与基础设施：Amtraker、DigiTraffic、多路 CCTV、WRI power plants。
- 其他：NUFORC、Polymarket/Kalshi、Shodan 手工覆盖层。

使用这些来源前必须回到当前代码、配置、attribution、health 和实际响应重新确认；“代码里有 fetcher”不等于当前可用或当前已取到数据。
